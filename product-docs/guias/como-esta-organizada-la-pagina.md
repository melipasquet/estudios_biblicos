# ¿cómo está organizada la página?

En la **barra lateral** vas a encontrar el acceso a los distintos **estudios**, organizados por categorías. Cada estudio contiene una **introducción** al libro o carta y un **abordaje capítulo a capítulo**, dividido por secciones.

Además, la página incluye una serie de **guías** para acompañar tu lectura:

* [cómo utilizar el material](como-utilizar-el-material.md),
* [cómo encarar un estudio devocional](como-encarar-un-estudio-devocional.md),
* y [preguntas para reflexionar](preguntas-para-reflexionar.md).
