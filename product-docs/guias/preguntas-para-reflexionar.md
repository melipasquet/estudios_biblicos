# Preguntas para reflexionar

#### Instrucciones para usar la Lista de preguntas

{% stepper %}
{% step %}
### Escogé un pasaje bíblico

Leé el texto cuidadosamente, incluso en diferentes versiones si es posible.
{% endstep %}

{% step %}
### Explorá las preguntas

No es necesario responder a todas las preguntas. Podés usarlas como una guía para reflexionar en general y profundizar en aquellas que más resuenen con vos en ese momento de tu estudio.
{% endstep %}

{% step %}
### Respondé las preguntas

Trabajá una sección a la vez, comenzando por el análisis del texto y avanzando hacia las reflexiones personales.
{% endstep %}

{% step %}
### Tomá notas

Registrá tus respuestas, ya sea digital o analógico, en donde quieras.
{% endstep %}

{% step %}
### Aplicalo a tu vida

Usá las respuestas de las secciones "Sobre el mensaje original" y "Para la vida actual" para identificar cambios prácticos, compromisos o aprendizajes que puedas aplicar en tu día a día.
{% endstep %}
{% endstepper %}

{% tabs %}
{% tab title="Sobre el texto" %}
* ¿Quiénes aparecen en el pasaje?
* ¿Qué hacen o dicen esas personas?
* ¿Qué preguntas o dudas plantea este texto?
* ¿Qué relación tiene este pasaje con los que lo preceden o lo siguen?
{% endtab %}

{% tab title="Sobre Dios" %}
* ¿Qué revela este pasaje sobre el carácter de Dios?
* ¿Qué atributos de Dios se pueden identificar (amor, justicia, fidelidad, etc.)?
* ¿Cómo interviene Dios directa o indirectamente en este pasaje?
* ¿Qué relación tiene Dios con los actores del pasaje?
{% endtab %}

{% tab title="Sobre el mensaje original (Exégesis)" %}
* ¿Cuál era el propósito del autor al escribir este texto? (Buscá quiénes eran los destinatarios: judíos, cristianos, iglesias específicas, etc.).
* ¿Qué sabemos sobre la cultura o las costumbres de esa época? (Buscá prácticas, tradiciones o ideas que aparecen en el texto y tratá de entender cómo eran en ese entonces. Por ejemplo, roles sociales, festividades o leyes mencionadas).
* ¿Hay símbolos o imágenes que aparecen en el texto? (Buscá el significado de esos símbolos en recursos bíblicos).
* ¿Hay palabras o frases que no entiendas? (Buscá en un diccionario bíblico online para descubrir su significado)
* ¿Cómo habrían entendido los lectores originales este mensaje?
{% endtab %}

{% tab title="Para la vida actual (Hermenéutica)" %}
* ¿Qué versículo del pasaje resuena más conmigo y por qué?
* ¿Qué me enseña este pasaje sobre mi vida personal o mi relación con Dios?
* ¿Hay alguna actitud o acción que debería cambiar a la luz de este texto?
* ¿Hay un ejemplo en este texto que deba seguir?
* ¿Cómo puedo aplicar este mensaje en mi vida cotidiana?
* ¿Hay alguna promesa a la que aferrarme o advertencia que atender?
* ¿Cómo puedo orar a partir de este pasaje?
* ¿Qué desafíos me plantea este texto para crecer espiritualmente?
* ¿Cómo puedo compartir la enseñanza de este pasaje con otros?
{% endtab %}
{% endtabs %}
